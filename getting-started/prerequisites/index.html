    Prerequisites¶

    Required software and dependencies for running the Multi-Agent Intelligent Warehouse.

    Required Software¶

    Software Version Check Command
    Python 3.11+ python3 --version
    Node.js 18.17.0+ (20.x LTS recommended) node --version
    npm (bundled with Node.js) npm --version
    Docker Latest stable docker --version
    Docker Compose v2+ docker compose version
    Git Latest stable git --version

    Node.js Version

    Node.js 18.0.0–18.16.x will fail with Cannot find module 'node:path' error. You need 18.17.0 or later. We recommend 20.x LTS for best compatibility.

    PostgreSQL Client¶

    Required for running database migrations.

    sudo apt-get install postgresql-client

    brew install postgresql
# or
brew install libpq

    Download from PostgreSQL downloads.

    See Deployment for running migrations through Docker without a local client.

    Poppler Utilities¶

    Required by pdf2image for PDF document processing.

    sudo apt-get install poppler-utils

    brew install poppler

    choco install poppler

    CUDA (Optional)¶

    Optional but recommended for RAPIDS GPU-accelerated forecasting.

    • Recommended: CUDA 12.x (default for RAPIDS packages)
    • Supported: CUDA 11.x (via install_rapids.sh auto-detection)
    • CUDA version is auto-detected during RAPIDS installation

    Tip

    If you have CUDA 13.x, the installer will use CUDA 12.x packages (backward compatible). Ensure your CUDA driver version matches or exceeds the toolkit version.
