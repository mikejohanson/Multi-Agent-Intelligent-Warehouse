    Deployment¶

    Complete deployment guide for the Warehouse Operational Assistant, including Docker Compose, self-hosted NIMs, and production deployment.

    Deployment Options¶

    Docker Compose (Development)¶

    The quickest way to get all infrastructure services running:

    ./scripts/setup/dev_up.sh

    This starts PostgreSQL/TimescaleDB, Redis, Milvus, and Kafka via Docker Compose.

    Complete Setup Guide (Jupyter Notebook)¶

    For a comprehensive, interactive setup:

    1. Open notebooks/setup/complete_setup_guide.ipynb in Jupyter Lab
    2. Follow the interactive cells step by step
    3. The notebook handles environment validation, database setup, and service startup

    NVIDIA NIMs Deployment¶

    The system uses NVIDIA NIMs (NVIDIA Inference Microservices) for LLM inference, embeddings, document processing, and content safety. All NIMs use OpenAI-compatible API endpoints.

    NIMs Overview¶

    NIM Service Model Purpose Environment Variable
    LLM Llama 3.3 Nemotron Super 49B Chat, reasoning, generation LLM_NIM_URL
    Embeddings llama-3_2-nv-embedqa-1b-v2 Semantic search for RAG EMBEDDING_NIM_URL
    NeMo Retriever NeMo Retriever Document preprocessing NEMO_RETRIEVER_URL
    NeMo OCR NeMoRetriever-OCR-v1 Intelligent OCR NEMO_OCR_URL
    Nemotron Parse Nemotron Parse Document parsing NEMO_PARSE_URL
    Small LLM nemotron-nano-12b-v2-vl Entity recognition LLAMA_NANO_VL_URL
    Guardrails NeMo Guardrails Content safety RAIL_API_URL

    Option 1: Cloud Endpoints (Recommended for Quick Start)¶

    Use NVIDIA-hosted endpoints — no infrastructure setup required.

    NVIDIA_API_KEY=your-nvidia-api-key-here

# LLM (49B model via brev.dev)
LLM_NIM_URL=https://api.brev.dev/v1
LLM_MODEL=nvcf:nvidia/llama-3.3-nemotron-super-49b-v1:dep-36ZiLbQIG2ZzK7gIIC5yh1E6lGk

# All other NIMs (via integrate.api.nvidia.com)
EMBEDDING_NIM_URL=https://integrate.api.nvidia.com/v1
NEMO_RETRIEVER_URL=https://integrate.api.nvidia.com/v1
NEMO_OCR_URL=https://integrate.api.nvidia.com/v1
NEMO_PARSE_URL=https://integrate.api.nvidia.com/v1
LLAMA_NANO_VL_URL=https://integrate.api.nvidia.com/v1
RAIL_API_URL=https://integrate.api.nvidia.com/v1

    Option 2: Self-Hosted NIMs (Recommended for Production)¶

    Deploy NIMs on your own infrastructure for data privacy, cost control, and lower latency.

    # Deploy NIMs via NVIDIA NGC containers
docker run --gpus all -p 8000:8000 \
  nvcr.io/nvidia/nim/llama-3.3-nemotron-super-49b:latest

# Point environment variables to your endpoints
LLM_NIM_URL=https://your-nim-host:8000/v1
LLM_MODEL=nvidia/llama-3.3-nemotron-super-49b-v1
EMBEDDING_NIM_URL=https://your-nim-host:8001/v1

    Option 3: Hybrid Deployment¶

    Mix cloud and self-hosted NIMs:

    LLM_NIM_URL=https://api.brev.dev/v1           # Cloud LLM
EMBEDDING_NIM_URL=https://your-nim-host:8001/v1  # Self-hosted embeddings
NEMO_RETRIEVER_URL=https://integrate.api.nvidia.com/v1  # Cloud document processing

    Getting NVIDIA API Keys¶

    1. Sign up at NVIDIA API Portal
    2. Generate an API key from your dashboard
    3. Set NVIDIA_API_KEY=your-api-key-here

    The same key works for all NVIDIA cloud endpoints.

    Post-Deployment Setup¶

    Database Migrations¶

    # Via Docker Compose
docker compose -f deploy/compose/docker-compose.dev.yaml exec -T timescaledb \
  psql -U warehouse -d warehouse < data/postgres/000_schema.sql

# Or from host with psql
PGPASSWORD=${POSTGRES_PASSWORD:-changeme} psql -h localhost -p 5435 \
  -U warehouse -d warehouse -f data/postgres/000_schema.sql

    Required migration files:

    • data/postgres/000_schema.sql
    • data/postgres/001_equipment_schema.sql
    • data/postgres/002_document_schema.sql
    • data/postgres/004_inventory_movements_schema.sql
    • scripts/setup/create_model_tracking_tables.sql

    Create Default Users¶

    python scripts/setup/create_default_users.py

    curl http://localhost:8001/health
curl http://localhost:8001/api/v1/version

    Database Maintenance¶

    # Weekly VACUUM
docker compose -f deploy/compose/docker-compose.dev.yaml exec timescaledb \
  psql -U warehouse -d warehouse -c "VACUUM ANALYZE;"

# Database backup
docker compose -f deploy/compose/docker-compose.dev.yaml exec timescaledb \
  pg_dump -U warehouse warehouse > backup_$(date +%Y%m%d).sql

    GPU Acceleration (RAPIDS)¶

    Install NVIDIA RAPIDS cuML for 10-100x faster forecasting:

    ./scripts/setup/install_rapids.sh
# Or manually:
pip install --extra-index-url=https://pypi.nvidia.com cudf-cu12 cuml-cu12

# Verify
python -c "import cudf, cuml; print('RAPIDS installed successfully')"

    Once installed, GPU acceleration is automatically detected and used. See the RAPIDS Setup Guide for details.
